# 🚀 Deployment

The portfolio is deployed using Vercel.

The deployment workflow is:

```text
Local Development
       ↓
    Git Commit
       ↓
    Git Push
       ↓
     GitHub
       ↓
     Vercel
       ↓
  Live Portfolio
```

Every new push to the `main` branch can trigger a new Vercel deployment when automatic deployments are enabled.
